## 🚀 Getting Started

To view the application online, simply click the link above:
👉 **[Launch NHL 32](https://breaultalex44-cmd.github.io/NHL32/)**

### Local Development

If you want to clone and run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/breaultalex44-cmd/NHL32.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd NHL32
   ```

3. **Open in browser:**
   Open `index.html` directly in your favorite web browser or use a live server extension (like Live Server in VS Code).
